2.1 What is an Array?

DEFINITION

An array is a collection of elements of the same data type, stored in contiguous (side-by-side) memory locations, accessed by a single name and an index.

Contiguity is the array's superpower and its curse. Because elements sit next to each other, the computer can jump to any element instantly — but it also means the whole block must be reserved in advance, and making room in the middle means physically shifting data.

REMEMBER

In C, array indices start at 0 and end at n−1. Writing marks[6] above is an out-of-bounds access — C won't stop you, it'll just read whatever garbage lives there. Classic bug, classic viva question.

2.2 Address Calculation — 1D Array

Because memory is contiguous, the address of any element can be computed with arithmetic — no searching required. This is the most asked formula of the chapter:

FORMULA
Addr(A[i]) = Base + (i − LB) × w
Base = address of first element · LB = lower bound (0 in C) · w = size of one element in bytes
EXAMPLE

Problem

An int array A[10] starts at address 2000 (LB = 0, each int = 4 bytes). Find the address of A[6].

Solution

Addr(A[6]) = 2000 + (6 − 0) × 4 = 2000 + 24 = 2024.

Note how it doesn't matter whether the array has 10 or 10 million elements — the jump is always one multiplication and one addition. That's O(1) access.

2.3 Two-Dimensional Arrays

A 2D array (a matrix) is stored in linear memory too — the compiler just flattens it row by row (row-major, used by C) or column by column (column-major, used by Fortran/MATLAB).

FORMULA — ROW MAJOR
Addr(A[i][j]) = Base + w × [(i − LR) × N + (j − LC)]
N = number of columns · LR, LC = lower bounds (usually 0)
FORMULA — COLUMN MAJOR
Addr(A[i][j]) = Base + w × [(j − LC) × M + (i − LR)]
M = number of rows
EXAMPLE

Problem

A[4][5] of ints (4 bytes), base = 1000, 0-based. Find Addr(A[2][3]) in both layouts.

Solution

Row-major: 1000 + 4 × (2×5 + 3) = 1000 + 4×13 = 1052

Column-major: 1000 + 4 × (3×4 + 2) = 1000 + 4×14 = 1056

Same element, different address — the layout changes the maths, not the data.

REMEMBER

The #1 exam mistake: swapping M and N. Row-major multiplies the row index by the number of columns; column-major multiplies the column index by the number of rows. Write the layout sketch first, then substitute.

2.4 Operations on Arrays

Traversal — O(n)

Visit every element once. Simple, but it's the base cost of everything that "scans" the array.

Insertion — O(n) worst case

To insert at position pos, every element from the end down to pos must shift right to open the slot:

  • Insert at end: O(1) — nothing to shift.
  • Insert at front / middle: O(n) — up to n shifts.
  • Also: arrays have fixed capacity — inserting into a full array means allocating a bigger block and copying everything.

IMPORTANT

Arrays win on access, linked lists win on insertion and deletion. "Which is better" is a trap question — the honest answer is always "depends on which operation dominates your workload".

2.7 Chapter Keypoints

KEY POINT

Arrays = same type + contiguous memory + index access.

KEY POINT

Addr(A[i]) = Base + (i−LB)×w — memorise, practise with LB = 1 variants.

KEY POINT

Row-major: i×columns. Column-major: j×rows. Don't swap.

KEY POINT

Insertion/deletion cost = number of elements shifted.
