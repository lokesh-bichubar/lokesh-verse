6.1 What is a Graph?

Trees model hierarchy — one boss, everyone below. But real relationships aren't hierarchical: friends connect to friends, cities to cities, web pages to web pages. A graph is the structure for "things connected to things", full stop.

DEFINITION

A graph is a non-linear data structure defined as G = (V, E), where V is a finite set of vertices (nodes) and E is a set of edges — each edge connecting a pair of vertices.

IMPORTANT

A tree is just a graph with no cycles and exactly one path between any two nodes. Every tree is a graph; almost no graph is a tree. Remember this hierarchy: graph ⊃ tree ⊃ binary tree.

6.2 Terminology

Table 6.1 — Graph vocabulary
TermMeaning
Adjacent verticesTwo vertices joined directly by an edge (neighbours)
Degree of a vertexNumber of edges touching it. For directed graphs: in-degree (incoming) + out-degree (outgoing)
PathSequence of vertices where each consecutive pair is joined by an edge
CycleA path that starts and ends at the same vertex
Connected graphA path exists between every pair of vertices
Weighted graphEach edge carries a cost (distance, time, price…)
DAGDirected Acyclic Graph — directed, no cycles; used for dependency / course prerequisite modelling
Complete graphEvery vertex connects to every other: n vertices → n(n−1)/2 edges (undirected)
REMEMBER

Handshake lemma: the sum of all degrees in an undirected graph is always 2 × |E| (every edge is counted twice, once per endpoint). A complete graph on n vertices has n(n−1)/2 edges — both are favourite one-liners in exams.

6.3 Types of Graphs

UNDIRECTED

Edges have no direction — A—B means you can travel both ways. Friendships, roads between cities.

DIRECTED (DIGRAPH)

Edges are arrows — A→B ≠ B→A. Twitter follows, web links, course prerequisites.

WEIGHTED

Edges carry numbers (cost, distance, latency). Maps and networks.

CYCLIC / ACYCLIC

Cycle present or not. DAG = directed + acyclic — the shape of dependencies and compilers' data flow.

6.5 Traversals — BFS & DFS

Two ways to walk a graph, and the contrast is beautiful:

  • BFS (Breadth-First Search) — explore level by level, like ripples in water. Uses a QUEUE. Finds shortest paths in unweighted graphs.
  • DFS (Depth-First Search) — dive as deep as possible, backtrack when stuck. Uses a STACK (or recursion). Finds cycles, topological order, connected components.
REMEMBER

BFS = Queue. DFS = Stack. If you remember one sentence from this chapter, make it this one — it's a guaranteed exam question and it cleanly links Chapter 06 back to Chapter 04.

EXAMPLE

Problem

Starting from vertex A, give one valid BFS order and one valid DFS order for the graph of Fig 6.1.

Solution

BFS: A, B, C, E, D — visit A; then A's neighbours B, C; then B's unvisited neighbour E; then C's unvisited neighbour D.

DFS: A, B, C, D, E — A → B → C → D → E, diving deep and only backtracking when there's nowhere new to go.

Both are valid traversals of the same graph — they just answer different questions: BFS = "what's nearby?", DFS = "where does this road lead?"

6.6 Applications of Graphs

  • Maps & navigation — Dijkstra's shortest path (Google Maps is a weighted graph problem).
  • Social networks — friends, followers, "friends of friends" (BFS at depth 2).
  • Web search — PageRank runs on the graph of links between pages.
  • Course prerequisites / build systems — DAGs + topological sorting.
  • Networks — routers, LAN topologies, delivery routes.
  • Dependency resolution — package managers (npm, pip) detect circular dependencies with DFS.
IMPORTANT

Complexities to quote in exams: BFS = O(V + E) with an adjacency list (O(V²) with a matrix); DFS = O(V + E) list, O(V²) matrix. Both visit everything once — the representation decides the cost of scanning neighbours.

6.7 Chapter Keypoints

KEY POINT

G = (V, E). Tree = connected + acyclic graph with n−1 edges.

KEY POINT

Σ degrees = 2|E|; complete graph = n(n−1)/2 edges.

KEY POINT

Matrix: O(V²) space, O(1) edge check. List: O(V+E) space — default for sparse graphs.

KEY POINT

BFS → queue, shortest path (unweighted). DFS → stack, cycles & topological order.
