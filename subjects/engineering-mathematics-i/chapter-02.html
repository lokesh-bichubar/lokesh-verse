2.1 The Derivative as a Limit

DEFINITION

The derivative of f at x is the limit of the average rate of change as the interval shrinks to zero:

FORMULA
f′(x) = limh→0 [f(x + h) − f(x)] / h
also written dy/dx — "a tiny change in y per tiny change in x"

Geometric meaning: the derivative is the slope of the tangent line at a point on the curve. Average rate = slope of a chord; the derivative is what that chord becomes when its two endpoints collapse into one.

EXAMPLE

Problem

Find f′(x) from first principles for f(x) = x².

Solution

f′(x) = limh→0 [(x+h)² − x²]/h = lim [2xh + h²]/h = lim (2x + h) = 2x.

"From first principles" = use the limit definition directly. Exams ask for it precisely to check you know where derivatives come from.

REMEMBER

Every "co-" function's derivative carries a minus sign: (cos)′ = −sin, (cot)′ = −cosec², (cosec)′ = −cosec·cot. If your derivative of a co-function came out positive, pause and re-check.

2.3 The Rules

PRODUCT RULE
(u · v)′ = u′v + u v′
"first d-second + second d-first"
QUOTIENT RULE
(u / v)′ = (u′v − u v′) / v²
"low d-high minus high d-low, over low squared" · v ≠ 0
CHAIN RULE
dy/dx = (dy/du) · (du/dx)
derivative of outside(at inside) × derivative of inside
EXAMPLE

Problem

Differentiate (a) x² sin x   (b) x/(x+1)   (c) sin(x²).

Solution

(a) Product rule: 2x·sin x + x²·cos x

(b) Quotient rule: [1·(x+1) − x·1]/(x+1)² = 1/(x+1)²

(c) Chain rule: cos(x²) · 2x = 2x cos(x²)

2.4 Implicit & Parametric Differentiation

When y is tangled inside an equation (implicit) or both x and y depend on a parameter t (parametric), you don't solve for y — you differentiate the relationship:

IMPLICIT
F(x, y) = 0  ⟹  dy/dx = −Fx / Fy
differentiate both sides w.r.t. x, treating y as a function of x (chain rule on every y-term)
PARAMETRIC
dy/dx = (dy/dt) / (dx/dt)
x = f(t), y = g(t) — divide the two rates
EXAMPLE

x² + y² = 25 ⟹ 2x + 2y(dy/dx) = 0 ⟹ dy/dx = −x/y. (Sanity check: a circle's slope at (3,4) is −3/4 — negative, going downhill left-to-right there. ✓)

2.5 Applications: Increasing, Decreasing, Maxima & Minima

The derivative's sign tells you the story of the curve:

  • f′(x) > 0 → f is increasing on that interval.
  • f′(x) < 0 → f is decreasing.
  • f′(x) = 0 → horizontal tangent — a critical point: candidate for max, min or neither.
IMPORTANT

Second Derivative Test: at a critical point where f′(c) = 0 — if f″(c) < 0 → local maximum (curve bends down); if f″(c) > 0 → local minimum (bends up); if f″(c) = 0 → test is inconclusive, use the sign-change (first derivative) test.

EXAMPLE — THE CLASSIC BOX PROBLEM

Problem

A farmer has 40 m of fence for a rectangular pen against a river (no fence needed on the river side). Maximise the area.

Solution

Let the side parallel to the river be x and the two perpendicular sides be y: x + 2y = 40, so A = x·y = (40 − 2y)·y = 40y − 2y².

A′(y) = 40 − 4y = 0 ⟹ y = 10, x = 20.

A″(y) = −4 < 0 ⟹ maximum. ✓ Area = 200 m².

Exam template: model → substitute the constraint → differentiate → set to zero → verify with second derivative → state the answer with units.

2.6 Rolle's Theorem & Lagrange's MVT

ROLLE'S THEOREM

If f is continuous on [a, b], differentiable on (a, b), and f(a) = f(b), then there exists at least one c ∈ (a, b) with f′(c) = 0. Between two equal heights there's a flat tangent.

LAGRANGE'S MEAN VALUE THEOREM

If f is continuous on [a, b] and differentiable on (a, b), there exists c ∈ (a, b) with:

FORMULA
f′(c) = [f(b) − f(a)] / (b − a)
some tangent is parallel to the chord joining the endpoints
REMEMBER

MVT is Rolle with a tilt: subtract the chord's slope and you're back to the flat case. In proofs/exams, always verify the hypotheses first (continuity + differentiability) — quoting the conclusion without conditions loses marks.

2.7 Chapter Keypoints

KEY POINT

f′(x) = slope of tangent = lim [f(x+h) − f(x)]/h.

KEY POINT

(uv)′ = u′v + uv′ · (u/v)′ = (u′v−uv′)/v² · chain: dy/dx = dy/du · du/dx.

KEY POINT

f′ > 0 increasing · f′ < 0 decreasing · f′ = 0 critical point.

KEY POINT

At critical points: f″ < 0 max, f″ > 0 min.

KEY POINT

Rolle: f(a)=f(b) ⟹ ∃c, f′(c)=0. MVT: f′(c) = (f(b)−f(a))/(b−a).

2.8 IMPORTANT QUESTIONS

IMPORTANT QUESTIONS
  1. Define the derivative as a limit and interpret it geometrically.
  2. Differentiate from first principles: (a) x³, (b) sin x, (c) 1/x.
  3. Differentiate: (a) x² ex, (b) (sin x)/(1 + cos x), (c) ln(tan x), (d) sin⁻¹(2x√(1−x²)).
  4. If x = at², y = 2at, find dy/dx (1/t).
  5. Find dy/dx for x³ + y³ = 3xy (Folium of Descartes).
  6. Find the maxima/minima of f(x) = x³ − 3x + 2 and classify each critical point.
  7. A rectangle's perimeter is 36 cm. Find dimensions that maximise its area (9 × 9 square).
  8. State and verify Rolle's theorem for f(x) = x² − 4x + 3 on [1, 3].
  9. State Lagrange's MVT and verify it for f(x) = x² on [2, 4] (c = 3).
  10. Show that f(x) = eˣ is increasing everywhere.
