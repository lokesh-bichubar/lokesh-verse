CHAPTER 01 • ENGINEERING MATHEMATICS – I

LIMITS & CONTINUITY

QUANTUM UNIVERSITY B.TECH CSE SEMESTER 01
FULL NOTES IMPORTANT QUESTIONS

1.1 The Idea of a Limit

Calculus begins with a deceptively simple question: what value is a function getting close to? Not "what value does it reach" — what it approaches. The limit is the destination, even if the function never actually arrives.

DEFINITION

Informal: limx→a f(x) = L means f(x) can be made arbitrarily close to L by taking x sufficiently close to a (from either side, but not necessarily at a). Formal (ε–δ): for every ε > 0 there exists δ > 0 such that 0 < |x − a| < δ implies |f(x) − L| < ε.

EXAMPLE

Problem

Investigate limx→2 (x² − 4)/(x − 2).

Solution

Direct substitution gives 0/0 — indeterminate, undefined at x = 2. But watch the approach:

  • x = 1.9 → f(x) = 3.9
  • x = 1.99 → f(x) = 3.99
  • x = 2.01 → f(x) = 4.01
  • x = 2.1 → f(x) = 4.1

Both sides squeeze toward 4. Factorise to confirm: (x²−4)/(x−2) = (x−2)(x+2)/(x−2) = x + 2 → 4 as x → 2. The hole at x = 2 doesn't matter — limits only care about the neighbourhood.

1.2 Left and Right Hand Limits

Approaching a from the left (x → a⁻) and from the right (x → a⁺) can give different answers — and that single fact decides whether a function is continuous:

FORMULA
limx→a f(x) = L  ⟺  LHL = RHL = L
Left Hand Limit = lim(x→a⁻) f(x) · Right Hand Limit = lim(x→a⁺) f(x)
IMPORTANT

The limit exists only if LHL = RHL. If they differ, the limit does not exist (DNE) — no amount of clever algebra saves it. For piecewise functions, always compute both sides separately at the joining point.

1.3 Algebra of Limits

Table 1.1 — If lim f = L and lim g = M, then…
RuleStatement
Sumlim [f + g] = L + M
Differencelim [f − g] = L − M
Productlim [f · g] = L · M
Quotientlim [f / g] = L / M  (M ≠ 0)
Constant multiplelim [k·f] = k·L
Compositionlim g(f(x)) = g(L) if g is continuous at L

1.4 Standard Limits (MEMORISE)

FORMULA SHEET
limx→0 sin x / x = 1  •  limx→0 tan x / x = 1
limx→0 (1 − cos x) / x = 0  •  limx→0 (1 − cos x)/x² = ½
all trigonometric standard limits — x in radians, always
FORMULA SHEET
limx→0 (1 + x)1/x = e  •  limn→∞ (1 + 1/n)n = e
limx→0 ln(1 + x)/x = 1  •  limx→0 (ex − 1)/x = 1
limx→0 (ax − 1)/x = ln a  •  limx→0 ((1+x)n − 1)/x = n
the exponential & logarithmic family — these six settle most exam questions
REMEMBER

The sin x / x family only works when the denominator → 0 and the angle is in radians. If you see limx→0 sin(5x)/x, rewrite as 5 · sin(5x)/(5x) → 5. Multiply and divide by the angle — that's the whole trick.

1.5 Indeterminate Forms

Substituting directly sometimes produces nonsense — forms that look like numbers but aren't. These are signals to use a technique, not final answers:

THE 7 FORMS
0/0  •  ∞/∞  •  0·∞  •  ∞−∞  •  0⁰  •  ∞⁰  •  1∞
if you get one of these, the answer is "not yet" — rewrite the expression

Technique 1 — Factorisation

For 0/0 with polynomials: factor and cancel the offending term.

EXAMPLE

limx→3 (x² − 9)/(x − 3) = lim (x−3)(x+3)/(x−3) = lim (x+3) = 6

Technique 2 — Rationalisation

For 0/0 with square roots: multiply by the conjugate.

EXAMPLE

limx→0 (√(1+x) − 1)/x — multiply by (√(1+x)+1)/(√(1+x)+1):

= lim [(1+x) − 1] / [x(√(1+x)+1)] = lim x/[x(√(1+x)+1)] = 1/(1+1) = ½

Technique 3 — L'Hôpital's Rule

FORMULA
lim f(x)/g(x) = lim f′(x)/g′(x)   (for 0/0 or ∞/∞ forms)
differentiate top and bottom SEPARATELY — this is not the quotient rule
REMEMBER

L'Hôpital is a last resort, not a first move — it works only on 0/0 or ∞/∞, and only after you verify the form. Applying it to a non-indeterminate limit gives a confidently wrong answer. Factorisation and standard limits are usually faster and safer in exams.

1.6 Continuity at a Point

DEFINITION

A function f is continuous at x = a if all three conditions hold: (1) f(a) is defined, (2) limx→a f(x) exists (LHL = RHL), (3) the limit equals f(a). Break any one and continuity breaks.

FORMULA
limx→a⁻ f(x) = limx→a⁺ f(x) = f(a)
three quantities, one number — the continuity test in one line

Types of discontinuity

REMOVABLE

Limit exists but ≠ f(a) (or f(a) undefined). A hole — "fixable" by redefining one point.

JUMP

LHL ≠ RHL — the graph teleports. Step functions live here. Unfixable.

INFINITE

Function blows up to ±∞ near a. Vertical asymptote, e.g. 1/x at x = 0.

EXAMPLE

Problem

f(x) = { x+2 if x < 2; x² if x ≥ 2 }. Is f continuous at x = 2?

Solution

LHL = lim (x+2) = 4. RHL = lim x² = 4. f(2) = 2² = 4. LHL = RHL = f(2) = 4 → continuous at x = 2. All three checks pass.

REMEMBER

For piecewise functions, the exam answer format is always the same three lines: compute LHL, compute RHL, compare with f(a). Write all three even if the answer is obvious — the marks are in the structure.

1.7 Continuity on an Interval & Algebra of Continuous Functions

f is continuous on (a, b) if it's continuous at every point inside; on [a, b] we also need one-sided continuity at the endpoints. The friendly consequences:

  • Polynomials are continuous everywhere — you can substitute directly.
  • Sums, products, quotients (non-zero denominator) and compositions of continuous functions are continuous.
  • sin x, cos x are continuous everywhere; tan x breaks where cos x = 0 (x = π/2 + kπ).
  • A continuous function on a closed interval [a, b] is bounded and attains its max and min (Extreme Value Theorem — the backbone of Chapter 02).

1.8 Chapter Keypoints

KEY POINT

Limit = approach value, not the value at the point. Holes don't matter.

KEY POINT

Limit exists ⟺ LHL = RHL.

KEY POINT

sin x/x → 1, (1+x)^(1/x) → e, (aˣ−1)/x → ln a — the holy trinity of standard limits.

KEY POINT

Continuity = defined + limit exists + they match. Discontinuities: removable, jump, infinite.

1.9 IMPORTANT QUESTIONS

IMPORTANT QUESTIONS
  1. Define the limit of a function (informal and ε–δ). What are LHL and RHL?
  2. Evaluate: (a) limx→3 (x²−9)/(x−3), (b) limx→0 (√(1+x) − 1)/x, (c) limx→0 sin 3x / sin 5x (3/5).
  3. Evaluate limx→0 (e3x − 1)/sin 2x (3/2).
  4. Evaluate limx→∞ (1 + 3/x)x (e³).
  5. List the seven indeterminate forms and name a technique for each situation.
  6. State L'Hôpital's rule with its conditions. Where does it fail?
  7. State the three conditions for continuity at a point.
  8. For f(x) = { 2x+1 if x < 1; 3 if x = 1; x+2 if x > 1 }, classify the discontinuity at x = 1 (removable; limit = 3 = f(1)? check LHL=3, RHL=3, f(1)=3 → actually continuous — trace it!).
  9. Distinguish removable, jump and infinite discontinuity with one example each.
  10. Show that polynomials are continuous everywhere.
