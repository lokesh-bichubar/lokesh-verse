MATRICES & DETERMINANTS

4.1 What is a Matrix?

DEFINITION

A matrix is a rectangular array of numbers arranged in m rows and n columns. Its order is m × n, and its entries are written aij — row index first, column index second.

A matrix is not a number — it's a container with its own algebra. You can't "solve" a matrix; you transform, combine and factor it. (A determinant |A|, on the other hand, is a single number computed from a square matrix — that distinction is worth a mark by itself.)

REMEMBER

Every square matrix splits as A = ½(A + Aᵀ) + ½(A − Aᵀ) — a symmetric part plus a skew-symmetric part. And in a skew-symmetric matrix the diagonal must be zero (aii = −aii forces it). Both are classic 2-mark theory questions.

4.3 Matrix Algebra

  • Addition: same order only; add entry-wise. Commutative, associative.
  • Scalar multiply: multiply every entry.
  • Multiplication: Am×n × Bn×p = Cm×p. Inner dimensions must match; entry cij = (row i of A) · (column j of B).
IMPORTANT

Matrix multiplication is NOT commutative: AB ≠ BA in general (and sometimes only one of them even exists). It is associative and distributive, and (AB)ᵀ = BᵀAᵀ — order reverses under transpose. Cancellation is also illegal: AB = O does not imply A = O or B = O.

4.4 Determinants

FORMULA — 2×2
|A| = a d − b c
for [[a, b], [c, d]] — cross products, minus the anti-diagonal
FORMULA — 3×3 (expansion)
|A| = a(ei − fh) − b(di − fg) + c(dh − eg)
expand along any row/column; sign pattern is the checkerboard + − +

Properties that do all the work

  • |Aᵀ| = |A| — rows and columns are interchangeable.
  • Swapping two rows (or columns) changes the sign.
  • Two identical rows/columns → |A| = 0.
  • Multiplying one row by k multiplies |A| by k (so |kA| = kⁿ|A| for n×n).
  • A row that is a multiple of another row → |A| = 0.
  • Adding a multiple of one row to another leaves |A| unchanged — the engine of row-reduction.
  • |AB| = |A|·|B| (same order square matrices).
  • Triangular matrix → |A| = product of diagonal entries.
DEFINITION

A square matrix is singular if |A| = 0, and non-singular if |A| ≠ 0. Only non-singular matrices have inverses.

4.5 The Inverse of a Matrix

FORMULA
A⁻¹ = adj(A) / |A|   (exists ⟺ |A| ≠ 0)
adj(A) = transpose of the cofactor matrix

Cookbook for A⁻¹ (2×2 shortcut included):

  • 2×2 shortcut: swap the diagonal, negate the off-diagonal, divide by |A|. For [[a,b],[c,d]]: (1/(ad−bc))·[[d,−b],[−c,a]].
  • General: build the cofactor matrix C (Cij = (−1)i+j·Mij, where Mij is the minor — delete row i, column j, take the determinant), transpose it to get adj(A), divide by |A|.
REMEMBER

Order matters in the check: A·adj(A) = adj(A)·A = |A|·I. If your exam answer doesn't satisfy A·A⁻¹ = I, it's wrong — the check takes 30 seconds and catches 90% of arithmetic slips.

4.6 Rank of a Matrix

DEFINITION

The rank of a matrix A (written ρ(A)) is the order of the largest non-zero minor — equivalently, the maximum number of linearly independent rows (or columns).

Practical method: row-reduce to echelon form (zeros below the staircase); the rank is the number of non-zero rows. Rank is invariant under row operations — that's why reduction works.

4.7 Solving Systems: AX = B

The grand finale: a system of n linear equations in n unknowns is a single matrix equation AX = B, and everything above was tooling for this.

CRAMER'S RULE
x₁ = |A₁|/|A|  •  x₂ = |A₂|/|A|  •  …  •  xₙ = |Aₙ|/|A|
Aᵢ = A with column i replaced by B · requires |A| ≠ 0
EXAMPLE

Problem

Solve: 2x + y = 7 and 3x − y = 3 by Cramer's rule.

Solution

|A| = |[2 1; 3 −1]| = 2(−1) − 1(3) = −5

|A₁| = |[7 1; 3 −1]| = 7(−1) − 1(3) = −10 → x = −10/−5 = 2

|A₂| = |[2 7; 3 3]| = 2(3) − 7(3) = −15 → y = −15/−5 = 3

Check: 2(2) + 3 = 7 ✓ and 3(2) − 3 = 3 ✓. Always check — Cramer arithmetic is where sign errors go to live.

REMEMBER

Homogeneous systems AX = O are never inconsistent — X = 0 is always a solution (the trivial one). Non-trivial solutions exist iff |A| = 0. That one line is asked every single year in some form.

4.9 IMPORTANT QUESTIONS

IMPORTANT QUESTIONS
  1. Define a matrix. Explain any six types with examples.
  2. Show that every square matrix is the sum of a symmetric and a skew-symmetric matrix.
  3. Prove that matrix multiplication is not commutative with a concrete 2×2 example.
  4. List any six properties of determinants and verify one of them numerically.
  5. Find the inverse of [[1, 2], [3, 4]] and verify A·A⁻¹ = I (|A| = −2).
  6. Define rank. Find the rank of a given 3×4 matrix by row reduction.
  7. Solve by Cramer's rule: x + y + z = 6, x − y + z = 2, 2x + y − z = 1.
  8. State the conditions for a system AX = B to have (a) unique, (b) no, (c) infinite solutions.
  9. For what value of λ does the homogeneous system have non-trivial solutions?
  10. If A is skew-symmetric, prove that A² is symmetric. What about odd powers?
