3.1 What is Integration?

Differentiation asks "what's the slope?" Integration asks the reverse question: "I know the rate — what was the function?" It's differentiation played backwards, plus one beautiful geometric meaning: area under the curve.

DEFINITION

Integration is the process of finding a function whose derivative is the given function. The result is called an antiderivative or indefinite integral:

FORMULA
∫ f(x) dx = F(x) + C   where   F′(x) = f(x)
indefinite = family of curves (shifted vertically) · definite = a number
REMEMBER

Never drop the +C in an indefinite integral. Because the derivative of any constant is 0, infinitely many antiderivatives exist — the + C is the difference between "all of them" and "a lucky guess". Exams dock a mark every single time.

3.3 Method 1 — Substitution

Spot a function and its derivative living in the same integral. Substitute the inner function as u, and the mess collapses:

FORMULA
∫ f(g(x)) · g′(x) dx = ∫ f(u) du   (u = g(x))
chain rule, run in reverse
EXAMPLE

Problem

∫ 2x · cos(x²) dx

Solution

Notice 2x is the derivative of x². Let u = x², du = 2x dx:

∫ cos(u) du = sin(u) + C = sin(x²) + C

Trigger to look for: whose derivative is sitting in the integrand? That's your u.

3.4 Method 2 — Integration by Parts (ILATE)

For products of unrelated families (a polynomial × a trig function, an exponential × a log…):

FORMULA
∫ u · v dx = u ∫v dx − ∫ [u′ · (∫v dx)] dx
shorthand: ∫u v = u∫v − ∫u′∫v — "integrate by parts"

Choosing which factor is u (the one you differentiate) matters enormously. The ILATE priority order decides:

I

Inverse trig (sin⁻¹, tan⁻¹…) — highest priority for u

L

Logarithmic (ln x) — has no simple integral, always make it u

A

Algebraic (x, x², polynomials)

T

Trigonometric (sin, cos)

E

Exponential (eˣ) — integrates happily, so it's v

EXAMPLE

Problem

∫ x ex dx

Solution

ILATE: Algebraic (x) beats Exponential (eˣ), so u = x, v = eˣ.

= x·eˣ − ∫ 1·eˣ dx = x eˣ − eˣ + C = eˣ(x − 1) + C

Try it the wrong way (u = eˣ) and you get ∫x²eˣ/2 — worse than you started. ILATE isn't a suggestion; it's the difference between finishing and looping forever.

3.5 Method 3 — Partial Fractions

For integrals of proper rational functions P(x)/Q(x) — degree of P < degree of Q — split the fraction into simple pieces you can integrate:

Table 3.2 — Factor in denominator → form to use

REMEMBER

If the fraction is improper (degree of numerator ≥ denominator), do polynomial long division first, then decompose the remainder. Splitting an improper fraction directly is the most common integration exam mistake after dropping +C.

3.6 Definite Integrals & Their Properties

FUNDAMENTAL THEOREM OF CALCULUS

If F is any antiderivative of f on [a, b], then: ∫ab f(x) dx = F(b) − F(a). Integration and differentiation are inverse processes — this is the theorem that makes calculus one subject instead of two.

Table 3.3 — Properties that save real time in exams
#PropertyMeaning
1∫ab f dx = −∫ba f dxSwapping limits flips the sign
2∫aa f dx = 0Zero-width interval
3∫ab = ∫ac + ∫cbSplit at any interior point
4∫0a f(x) dx = ∫0a f(a−x) dxKing property — makes hard limits symmetric
5∫−aa even f = 2∫0a fEven function: mirror symmetry
6∫−aa odd f = 0Odd function: cancels — no computation needed!
IMPORTANT

Check odd/even before computing anything. ∫−ππ x³ cos x dx looks nightmarish until you notice x³·cos x is odd (odd × even = odd) — so the answer is instantly 0. Ten seconds of symmetry checks can be worth ten minutes of integration.

EXAMPLE

Problem

∫0π/2 sin x/(sin x + cos x) dx

Solution

King property (Table 3.3, #4) with a = π/2: I = ∫0π/2 cos x/(cos x + sin x) dx.

Add the two forms: 2I = ∫ (sin x + cos x)/(sin x + cos x) dx = ∫ 1 dx = π/2.

So I = π/4 — no actual integration of the original fraction required. That's the property table earning its keep.

3.7 Chapter Keypoints

KEY POINT

∫f dx = F + C. +C always (indefinite only).

KEY POINT

Substitution when you see a function and its derivative together.

KEY POINT

By parts for unrelated products. ILATE picks u: Inverse → Log → Algebraic → Trig → Expo.

KEY POINT

∫ab f = F(b) − F(a). Swap limits → sign flip.

KEY POINT

Odd function over [−a, a] → 0 instantly. Even → double the half.

3.8 IMPORTANT QUESTIONS

IMPORTANT QUESTIONS
  1. Define an indefinite integral. Why is the constant of integration necessary?
  2. Evaluate: (a) ∫ (3x² + 2x − 5) dx, (b) ∫ sin²x dx, (c) ∫ (ln x)/x dx.
  3. Evaluate by substitution: (a) ∫ x √(x² + 1) dx (⅓(x²+1)^3/2), (b) ∫ tan³x sec²x dx.
  4. Evaluate by parts: (a) ∫ x cos x dx, (b) ∫ ln x dx (x ln x − x), (c) ∫ eˣ sin x dx (eˣ(sin x − cos x)/2).
  5. State the ILATE rule. Why does the wrong choice of u make an integral harder?
  6. Resolve into partial fractions and integrate: 1/(x² − 5x + 6).
  7. State the Fundamental Theorem of Calculus.
  8. Prove that ∫−aa odd-function dx = 0, with one example.
  9. Evaluate ∫0π/2 sin x/(sin x + cos x) dx using properties (π/4).
  10. Evaluate ∫1e (1 + ln x)/x dx.
