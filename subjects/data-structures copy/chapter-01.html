CHAPTER 01

INTRODUCTION TO DATA STRUCTURES

DATA STRUCTURES • SEMESTER 01

FULL NOTES ~10 MIN READ

Before we write a single line of code, we need to answer one question: how do we keep data so our program can actually use it well? That's the whole game of this chapter — and honestly, of this entire subject.

1.1 What is a Data Structure?

A data structure is a way of organizing and storing data so that it can be accessed and modified efficiently. Think of it as the difference between dumping all your clothes in one pile versus sorting them into drawers — same clothes, very different time to find a sock.

DEFINITION

A data structure is a specialized format for organizing, storing and managing data in a computer so that it can be used efficiently — efficient in both time (how fast operations run) and space (how much memory is used).

Every program you have ever used — a phone dialer, a game, Instagram — is really just data + operations on that data. The structure you choose decides how cheaply those operations run.

1.2 Why Do We Need Data Structures?

As the amount of data grows, poorly organized data makes programs painfully slow. Structured data lets us design operations that scale.

IMPORTANT

Choosing the right data structure can be the difference between a program that finishes in seconds and one that takes hours. Structure choice is a design decision, not an afterthought.

EXAMPLE

Phone contacts. If your phone stored 5,000 contacts in one unsorted pile, finding "Aarav" would mean scanning up to 5,000 names every time. Instead, contacts are kept sorted alphabetically, so the phone jumps straight to the "A" section. Same data — smarter structure — instant result.

1.3 Classification of Data Structures

Data structures come in a family tree. At the top level we split them into primitive (built into the language) and derived (built from primitives). Derived structures are further split by how their elements are arranged: linear (one after another) or non-linear (hierarchical / connected).

Category Examples Core Idea
Primitive int, float, char, boolean Single values, built into the language.
Derived → Linear Array, Linked List, Stack, Queue Elements arranged sequentially, one after another.
Derived → Non-Linear Tree, Graph Elements connected hierarchically or in networks.
KEY POINT
  • Linear: traversal visits elements in one sequence (e.g. array index 0 → 1 → 2…).
  • Non-linear: one element can connect to many (e.g. a tree node with children).

1.4 Arrays — Your First Data Structure

An array stores elements of the same type in contiguous memory locations. Because the memory is continuous, the address of any element can be computed directly — which is why accessing A[i] takes the same time no matter how big the array is.

FORMULA

Loc(A[i]) = Base(A) + (i − L) × W

Base(A) = starting address • i = index • L = lower bound (often 0) • W = size of one element in bytes

PYTHON — ARRAY BASICS 
# an array (list) of marks — same kind of data together
marks = [78, 91, 64, 88]

# ACCESS — jump straight to an index, O(1)
print(marks[2])        # 64

# UPDATE — overwrite a value at an index
marks[0] = 85

# INSERT at the end — cheap
marks.append(72)

# TRAVERSAL — visit every element once
for m in marks:
    print(m, end=" ")   # 85 91 64 88 72
REMEMBER

Arrays give fast access (indexing is instant) but slow insertion/deletion in the middle — elements must be shifted. No structure is "best"; each is a trade-off. We fix the shifting problem later with linked lists.

1.5 Quick Revision

Five lines to re-read the night before the exam:

DEFINITION

Data structure = organized storage for efficient access & modification.

WHY

Right structure → fast programs even with huge data.

TYPES

Primitive vs derived. Linear vs non-linear.

ARRAYS

Contiguous memory • O(1) access • costly middle inserts.

FORMULA

Loc(A[i]) = Base + (i − L) × W

EXAM ALERT

"Define data structure and classify it with a diagram" is a classic 5-marker. Memorize the classification table from §1.3 — it carries full marks.
